# Clone link foundation — internal linking, sitemap, white-hat backlink plan

## 1. Internal linking structure (clone pages)

Pages: `/` (index.html), `/demo/` (demo.html — the working copilot), `/pricing/` (pricing.html).

- **index.html** → demo (primary CTA "Try the live demo" in hero + nav), pricing (nav + "See pricing" under stats), features sections link to demo with mode anchors (`demo.html?mode=technical`, `?mode=sales`, `?mode=recruiting`), FAQ links to pricing + demo.
- **demo.html** → index (logo + "Back to home"), pricing ("Need hosted AI? See plans"), footer links to all pages.
- **pricing.html** → index, demo ("Try it free first — no card"), comparison table links to demo.
- **Footer (all pages):** Home · Live demo · Pricing · Analysis (ANALYSIS.md is not public; footer links only the three pages) + the affiliation disclaimer.
- **sitemap.xml** lists all three pages (see `sitemap.xml` in this repo). robots.txt allows all and points to the sitemap.

## 2. White-hat backlink plan (legitimate only)

Rules (Zohaib's standing rule): legitimate levers only — no paid links, no link farms, no spam, no scraped outreach lists, no ban-risk tactics. Outreach and submissions are NOT part of this build; the plan + the 10 ready listings below are the deliverable. The clone is an unofficial rebuild — every listing must describe it honestly as a free browser demo inspired by Natively, never as Natively the company.

Strategy, in order: (1) put the clone's code on GitHub as a public repo with a README linking back (mirrors how the original earns links); (2) launch listings on free product directories; (3) one honest build-log article (dev.to) + one Show HN post; (4) comparison/roundup inclusion by asking (not paying) for a listing where the clone genuinely fits.
