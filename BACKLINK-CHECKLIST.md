**Do NOT submit them from the agent side** — every listing below needs the owner's
accounts and taps. Work down this list in order; each row gives the site, where to
submit, and exactly what to paste (copy from `BACKLINKS.md`, section 3).

## Rules (standing — do not break these)

- Describe the clone honestly as a **free browser demo inspired by Natively** — never
  as Natively the company.
- No paid listings: if a directory asks for payment, skip it.
- No link farms, PBNs, mass blasts, scraped outreach, or fake reviews.
- One listing per site; do not re-submit a rejected listing without fixing the reason.

## First, before any of this

Put the clone's code on GitHub as a public repo with a README linking back to
https://natively-clone.pages.dev/ — that mirrors how the original earns its links
(GitHub stars → trending lists → articles) and gives every directory a real project
page to point at.
